# NileFlix

NileFlix is a Next.js 16 movie and TV discovery app powered by TMDB data. It renders curated movie and series rows on the home page, supports search, and provides separate detail and watch pages for movies and TV episodes.

For the current project snapshot, architecture notes, routes, and known limitations, see [docs/PROJECT_STATUS.md](docs/PROJECT_STATUS.md).

## Quick Start

1. Install dependencies with `npm install`.
2. Set `TMDB_API_KEY` in your environment.
3. Start the app with `npm run dev`.

Open `http://localhost:3000` after the dev server starts.
